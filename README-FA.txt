پروژه اندرویدی مدیریت شخصی علی و فندق

این پروژه یک پوسته اندرویدی WebView برای نسخه آنلاین فعلی برنامه است.
آدرس برنامه: https://modiriat-talebi-test.alit18853.workers.dev

ساخت APK:
1) کل پوشه را در یک مخزن GitHub بارگذاری کنید.
2) در GitHub وارد زبانه Actions شوید.
3) گردش کار Build Android APK را انتخاب و Run workflow را اجرا کنید.
4) پس از پایان موفق، در بخش Artifacts فایل modiriat-ali-va-fandogh-apk را دانلود کنید.
5) فایل app-debug.apk داخل ZIP را روی گوشی نصب کنید.

مجوز میکروفون در زمان استفاده درخواست می‌شود. برنامه برای اجرا به اینترنت نیاز دارد چون نسخه وب و سرور فعلی را باز می‌کند.
این خروجی هنوز APK نیست؛ سورس آماده ساخت APK است. برای ساخت محلی به Android SDK و Gradle نیاز است.
